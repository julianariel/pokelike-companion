# Security Policy

## Supported Versions

Only the latest `main` release is supported.

## Reporting Issues

This is a private repository. Open a private GitHub issue or contact the repository owner directly for security concerns.

## Extension Boundaries

The companion is designed to be read-only:

- It reads Pokelike localStorage and visible screen text.
- It does not automate clicks.
- It does not send game state to a third-party service.
- It does not mutate Pokelike cloud saves.
